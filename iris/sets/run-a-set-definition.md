# Run a set definition
{: .no_toc }

Once a set definition has been created, it can be used over and over to filter records in realtime. As more records are created, the set will find them with no modifications, enabling powerful filtering for organizations an people.

## Run a set definition

Navigate to either `Resources` -> `Organizations` or `Resources` -> `People`.

In the `All Sets` dropdown, select the set that you have created.

The resources are filtered according to the criteria in the set.

To unfilter, set the dropdown back to `All Sets`.
