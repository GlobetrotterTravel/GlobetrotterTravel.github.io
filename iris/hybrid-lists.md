# Hybrid lists
{: .no_toc }

A hybrid list is a globally-available categorised collection of items, available to all organizations.

Hybrid lists are specified by a unique name and a description. Each hybrid list is made up of one or more categories which are also specified by a unique name and a description. Each category is made up of one or more items which are specified by a name and a value.

Organizations can use the items on a hybrid list to drive business processes in a consistent manner. For example, a hybrid list could be used to store a list of fees that are standard across all entitities. The real power of hybrid lists is that organizations can have standard items in a hybrid list category selectively replaced with custom items that are specific to that organization. This allows for a high degree of standardisation while still allowing for customisation.
