# Delete a field definition
{: .no_toc }

When a field definition is deleted, all field instances associated with the field definition are also deleted. For this reason, deleting field definitions should be considered carefully.

## Delete a field definition

To delete a field definition, open the `Definitions` navigation menu and click `Field Definitions`.

Locate the field definition to be deleted.

Click the `Trash Can` icon. A confirmation dialog appears.

Click `Delete`.

The field definition, and all of the instances associated with it are deleted.
