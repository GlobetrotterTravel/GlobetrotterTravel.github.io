# Delete a facet definition
{: .no_toc }

When a facet definition is deleted, all facet instances associated with the facet definition are also deleted. For this reason, deleting facet definitions should be considered carefully.

## Delete a facet definition

To delete a facet definition, open the `Definitions` navigation menu and click `Facet Definitions`.

Locate the facet definition to be deleted.

Click the `Trash Can` icon. A confirmation dialog appears.

Click `Delete`.

The facet definition, and all of the values associated with the target resource are deleted.
