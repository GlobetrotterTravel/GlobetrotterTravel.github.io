# Reset a secret
{: .no_toc }

To reset a secret, navigate to the `System` navigation menu and click `Secrets`.

Locate the secret you want to reset and click the `Edit` icon.

In the `Value` field, set a new secret value.

Click `Save`. The secret is updated.
