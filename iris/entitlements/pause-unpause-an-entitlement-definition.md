# Pause or unpause an entitlement definition
{: .no_toc }

When an entitlement definition is paused, all entitlement instances associated with the entitlement definition are also paused.

## Pause an entitlement definition

To pause an entitlement definition, open the `Definitions` navigation menu and click `Entitlement Definitions`.

Locate the entitlement definition to be paused.

Click the `Pause` icon.

The entitlement definition, and all of the entitlement instances are paused.

## Unpause an entitlement definition

To unpause an entitlement definition, open the `Definitions` navigation menu and click `Entitlement Definitions`.

Locate the entitlement definition to be enabled.

Click the `Play` icon.

The entitlement definition, and all of the entitlement instances are made active again.
