# Delete an entitlement definition
{: .no_toc }

When an entitlement definition is deleted, all entitlement instances associated with the entitlement definition are also deleted. For this reason, deleting entitlement definitions should be considered carefully.

## Delete an entitlement definition

To delete an entitlement definition, open the `Definitions` navigation menu and click `Entitlement Definitions`.

Locate the entitlement definition to be deleted.

Click the `Trash Can` icon. A confirmation dialog appears.

Click `Delete`.

The entitlement definition, and all of the values associated with the target resource are deleted.
