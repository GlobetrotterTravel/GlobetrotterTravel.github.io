# Setting or Resetting a Property Value

Properties control various behaviours of your Iris tenant. They are defined within the system but configurable by tenant administrators.

Unset properties use the default value for the property definition. 

## Setting a property value

To set a property value, navigate to the `System` navigation menu and click on `Property Values`.

Locate the property value you want to modify and click the `Edit` icon. The `Edit Property Value` dialog appears.

> 🛈 The property name and description cannot be modified.

In the `Value` field, set the string value for the property.

> 🛈 The value supplied must comply with the regex specified by the `Pattern`.

Click `Save`. The property value is saved.

## Resetting a property value

To reset a property value back to default, navigate to the `System` navigation menu and click on `Property Values`.

Locate the property value you want to modify and click the `Trash Can` icon.

The property value is reset to default.
